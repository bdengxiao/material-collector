# 使用与恢复

名单第一行应为表头，编号用文本。Excel 原有精度或前导零已丢失时，软件不能可靠还原，请回到原始文本来源。

人工确认页可筛选待确认、失效/需复核、重复和已忽略。选中文件后选择正确人员与类别，再确认。清除归属会清空当前归属，不是历史撤销；忽略/恢复不会删除原材料。

规则修改后，未受影响的人工确认保留，受影响裁决需重新确认。源文件移动、替换或变化时恢复原路径并重扫；无法恢复的文件可明确忽略，缺件仍在报告中体现。

保存 `.msq` 项目后可重开，上一版通常在 `.msq.bak`；保存逻辑还可能保留 `.history-编号.msq`。这些文件包含人员与路径，勿公开上传。项目恢复不等于源材料恢复。

导出目录必须与源目录互不包含。先预览再确认；重复导出创建新目录。字节校验仅检查复制一致，不检查材料内容合格。失败或取消时查看提示及未完成目录中的导出记录，不交付 `.partial` 或未完成输出。

遇源文件占用、路径过长或权限错误，先保留原件，解决原因或将合成复现材料复制至较短的可访问本地路径后重试。不要关闭系统防护或更改系统安全设置来绕过提示。
