# 材料收齐助手 · Material Collector

用于班级、社团与活动报名的本地 Windows 材料核对工具。导入名单和材料文件夹，查看缺件、人工纠正归属，再复制整理并输出 Excel 与 ZIP。

**文件已找到不代表材料内容审核合格。** 本工具不审核照片质量、证明真伪或表格填写内容。

当前源码界面版本为 **0.2.2 试用候选**。首次公开以源码为主；Windows 下载包将在核对发行依赖与对应版本后单独发布。

## 功能

- 导入 CSV / XLSX，预览并选择姓名与编号列；提示前导零和长数字风险。
- 配置多类材料、扩展名、必交项、允许多份和关键词，提供三个起步模板。
- 递归扫描，按完整编号与明确姓名边界保守匹配；身份冲突需人工处理。
- 搜索、筛选缺件、查看人员详情；人工指定人员及类别，忽略或恢复副本。
- 保存项目与备份；增量扫描补交材料，变更或失效文件需重新核对。
- 预览整理路径，复制到独立目录，生成三份 Excel 和 ZIP；校验文件字节一致。

源材料只读取，不移动、不改名。程序不上传材料，不要求登录。

## 从源码运行（Windows PowerShell）

需要 Python 3.12。克隆或下载源码后，在项目目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\app.py
```

先点击“使用 10 人虚构示例”，观察 7 人已找到全部必交文件、3 人缺件和匿名文件。示例为合成数据，没有真实人员材料。

## 使用流程

1. 新建任务，导入有表头的名单；编号建议用文本保留 `0012` 等前导零。
2. 应用模板或配置规则，选择材料文件夹开始核对。
3. 查看缺件；到人工确认页处理重名、冲突和类别不确定的文件。
4. 选中文件、人员和类别，确认更正。“清除归属”只将当前归属置为待确认，**不是恢复上一操作的历史撤销**。
5. 规则修改后，只要求受影响的人工确认复核；原归属仅留作参考。
6. 文件失效先恢复原路径并重扫；无法恢复时可明确忽略，缺件报告仍保留未齐人员。
7. 保存项目；选择与材料目录互不包含的输出目录，预览后导出。

详见 [使用说明](docs/usage.md)。

## 测试与构建

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm MaterialCollector.spec
```

构建输出为 `dist/MaterialCollector/`，须保留完整目录。自行构建的二进制在分发前需检查全部第三方依赖许可，见 [第三方声明](THIRD_PARTY_NOTICES.md)。

测试使用虚构数据，包含 10/100/1000 人规模。自动化、Qt 离屏渲染与真实前台操作是不同证据；测试结果不能代表所有 Windows 环境或真实用户均已通过。

## 限制

仅 Windows 为主要目标，其他系统、干净电脑和所有 Windows 版本的兼容性未获全面验证。XLSX 读取活动工作表，不支持旧 XLS；压缩包不解压；无 OCR、在线收集、自动催交、模糊匹配或材料内容审核。

取消按文件与阶段检查，正在处理的大文件可能需要等待。失败或取消的输出不得作为正式交付。保存项目包含姓名、编号及本地路径，请自行保护隐私。
